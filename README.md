# SORTING
This file display the execution times of some sorting algorithms.
Every single algorithms manipulate the same vector of **100000** elements, in this way the comparison between the times are more accurate.
Vector is randomly generated evrey time the program is run.
Results are in the *benchMark.csv* file.
### Algorithms list:
- Bouble sort
- Insertion sort
- Selection sort
- Merge sort
- Quick sort
- Counting sort
